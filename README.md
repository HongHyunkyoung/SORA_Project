# 🌙 SORA — Seoul Risk Analytics for Women & Aged

> **서울시 여성 안전 인프라 개선 시급도 분석**  
> 데이터로 안전 사각지대를 찾고, 더 안전한 도시를 만들기 위한 정책 지원 도구

---

## 📌 프로젝트 개요

체감 안전도와 실제 위험 사이의 괴리를 데이터로 밝혀냅니다.  
서울시 25개 자치구의 **취약성(X)** 과 **방어력(Y)** 을 정량화하여  
인프라 투자가 가장 시급한 지역을 도출하는 **개선 시급도 지수(Z)** 를 개발했습니다.

- **팀명**: 지금, 잠이 옵니까?
- **기간**: 2025년 10월
- **데이터**: 서울시 공공데이터 (성범죄 통계, CCTV 현황, 경찰 인프라 등)

---

## 🎯 문제 정의

| 문제 | 내용 |
|------|------|
| 불균형한 안전 인프라 | CCTV·경찰력이 위험 수준에 비해 부족한 지역 존재 |
| 여성·노인 취약성 | 여성 독거노인 등 스스로 방어하기 어려운 인구 집중 지역 |
| 기존 방식의 한계 | 단순 범죄 통계만으로는 '어디에 먼저 투자해야 하는가' 판단 불가 |

---

## 🔧 분석 방법론

### 분석 구조: 취약성(X) vs 방어력(Y)

**취약성(X) 변수** — 높을수록 위험
- 성범죄 건수, 성폭력 위험 지수, 여성 독거노인 수

**방어력(Y) 변수** — 높을수록 안전
- CCTV 설치 수, 안심벨 설치 수, 지구대/파출소 수, 치안센터, 경찰관 수

### 7단계 분석 파이프라인

```
1단계: 데이터 로드 및 병합        → 공공데이터 CSV 통합, 결측치 처리
2단계: 취약성·방어력 점수 계산    → MinMaxScaler 정규화 후 종합 점수화
3단계: 개선 시급도 지수 산출      → Z = X / Y (비율 기반 시급도)
4단계: 0~100점 스케일링           → 직관적 해석을 위한 변환
5단계: 상관관계 분석 (Heatmap)   → p-value 기반 통계적 유의성 검증
6단계: 지도 시각화 (Folium)       → 서울시 지도 위 시급도 색상 표현
7단계: 외부 검증                  → 112 신고·5대 범죄와의 상관관계 검증
```

---

## 📊 주요 결과

### 개선 시급도 상위 지역
| 순위 | 자치구 | 특징 |
|------|--------|------|
| 1위 | 관악구 | 취약성 높으나 방어 인프라 부족 |
| 2위 | 강서구 | 인프라 대비 위험 요인 과다 |
| 3위 | 강동구 | 방어력이 취약성을 충분히 상쇄 못함 |

### 모델 검증 결과
- 시급도 지수 ↔ 112 신고 건수: **상관계수 0.61** (p < 0.001)
- 시급도 지수 ↔ 5대 범죄 건수: **상관계수 0.51** (p < 0.001)
- → 모델이 실제 치안 위험을 효과적으로 반영함을 외부 데이터로 입증
